# 🔑 لوحة تحكم الاشتراكات والتراخيص الخاصة (Locate Go Admin Portal)
### مزودة بنظام ربط مباشر بقاعدة بيانات Firebase ودعم كامل للعمل دون إنترنت (Offline Mode)

هذه اللوحة **منفصلة ومستقلة تماماً** عن تطبيق السائقين؛ تم إزالة أي أزرار أو روابط للمشرف من داخل تطبيق المستخدمين لتضمن الخصوصية التامة والسرية بنسبة 100%.

---

## ⚡ دعم قاعدة بيانات Firebase في وضع الأوفلاين (Offline Firebase Database):
1. **قاعدة بيانات سحابية مباشرة (Firebase Realtime Database)**:
   - اللوحة متصلة مباشرة بقاعدة بيانات فايربيس على المسار:
     `https://appprotector-79e9c-default-rtdb.firebaseio.com/activation_codes`
   - يتم مزامنة الأكواد الجديدة، التمديدات، وحالات الأجهزة لحظياً مع هواتف المناديب وتطبيق Locate Go.
2. **العمل دون إنترنت بنسبة 100% (Offline-First Storage)**:
   - في حال عدم وجود اتصال بالإنترنت أو نوم الخادم، تفتح اللوحة فوراً في **0 ثانية** وتستعرض كافة الأكواد المخزنة محلياً.
   - يمكنك إنشاء أكواد جديدة، تمديدها، حظرها، أو فك ارتباط الأجهزة حتى وأنت غير متصل بالإنترنت.
   - يتم إدراج التعديلات في قائمة انتظار أوفلاين (Pending Queue) وتُرفع تلقائياً لفايربيس والسيرفر فور استعادة الاتصال بالإنترنت!
3. **أدوات النسخ الاحتياطي (Offline Backup & Restore)**:
   - تصدير نسخة احتياطية من الأكواد بصيغة JSON بنقرة واحدة.
   - استيراد واستعادة الأكواد من ملف JSON في وضع الأوفلاين.

## 🚀 خيارات الرفع والاستضافة المجانية (خلال 30 ثانية)

### الخيار 1: التشغيل المحلي المباشر بدون رفع (Offline / Local)
- يمكنك ببساطة النقر مرتين على ملف `index.html` في جهاز الكمبيوتر أو الجوال ليفتح معك مباشرة في متصفحك (Chrome، Safari، Edge) دون الحاجة لرفعه إطلاقاً!

### الخيار 2: استضافة مجانية وفورية عبر Netlify Drop (أسهل خيار - بدون أي تثبيت)
1. افتح الرابط: [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. اسحب مجلد `admin-portal` وأفلته داخل الصفحة.
3. مبروك! سيتم تزويدك برابط فوري خاص بك (مثال: `https://locate-admin-xyz.netlify.app`).
4. افتح الرابط واستمتع بإدارة وتوليد أكواد الاشتراكات في أي وقت ومن أي جهاز.

### الخيار 3: الرفع على استضافة Vercel المجانية
1. سجل دخولك على [https://vercel.com](https://vercel.com)
2. اختر **Add New Project** ثم ارفع مجلد `admin-portal`.
3. اضغط **Deploy**.
4. ستحصل على رابط رسمي سريع ومحمي بشهادة SSL مجانية.

## 🛡️ الحماية ضد التفكيك والهندسة العكسية (Anti-Decompilation):
- تطبيق المناديب (APK) لا يحتوي على أي أثر لملفات الإدارة، أو روابطها، أو أزرارها.
- كافة طلبات الإدارة تتطلب ترويسة أمان `X-Admin-Key` المشفرة؛ وأي محاولة وصول بدون هذا المفتاح تُرجع رمز `404 Not Found` وكأن المسار غير موجود إطلاقاً لمنع أي استكشاف أو هجوم.
- ملفات بناء وتجميع الأندرويد تم ضبطها لاستثناء أي ملفات لوحة تحكم أو تعليمات من ملف APK النهائي.

## 💎 ميزات لوحة التحكم:
- **توليد أكواد اشتراك**: باقات جاهزة (تجربة يوم، شهر، شهرين، 3 أشهر، 6 أشهر، سنة، أو مخصص بالأيام).
- **الربط الحصري بمعرف الجهاز (Device ID Binding)**: تحديد معرف جهاز المندوب لكي لا يعمل الكود إلا على هاتفه فقط.
- **بدء الصلاحية الذكي**: يبدأ احتساب الأيام من أول تفعيل يقوم به المندوب.
- **تمديد الاشتراكات**: إضافة +30 يوماً بنقرة واحدة.
- **فك ارتباط الجهاز**: لنقل الاشتراك إلى جوال جديد إذا قام المندوب بتغيير هاتفه.
- **تعطيل وحظر الأكواد**: لإيقاف أي مندوب مخالف فوراً.
- **إرسال مباشر عبر واتساب**: مشاركة الكود ومعرف الجهاز والمدة برسالة مهيأة مسبقاً بنقرة زر.
- **مزامنة فورية ودعم أوفلاين كامل**: يعمل دائماً مع أو بدون إنترنت.
